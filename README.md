# Immo Colucci — Site immobilier

Site vitrine + back-office pour une agence immobilière et de conciergerie à Agadir (Maroc).

## Stack technique

- **PHP 8.2** (MVC maison, sans framework)
- **MySQL** via PDO
- **HTML / CSS / JavaScript** vanilla
- **Apache** (XAMPP en local)

## Fonctionnalités

### Site public
- Page d'accueil (hero, biens à la une, services, contact)
- Liste des biens avec filtres
- Fiche détaillée d'un bien (galerie, description, équipements)
- Blog / articles
- Chatbot assistant
- Formulaire de contact

### Back-office (`/admin/`)
- Authentification sécurisée (rôles admin/éditeur)
- Tableau de bord avec statistiques
- Gestion des biens (CRUD complet + upload photos)
- Médiathèque
- Gestion des messages de contact
